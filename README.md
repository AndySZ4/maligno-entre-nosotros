# Hay un maligno entre nosotros

Presentación interactiva tipo juego (caricatura de los años 30) que cuenta un laboratorio académico de clasificación de tumores de mama con el conjunto **Breast Cancer Wisconsin (Diagnostic)**: cinco modelos, el umbral de decisión, la curva ROC y su lectura para clínicos y para todo público.

**Ver en línea:** https://andysz4.github.io/maligno-entre-nosotros/

- Funciona en computadora y en celular (vista de diapositiva o de lectura).
- Controles con la barra de botones o el teclado (→ ← ↑ ↓, D, C, N, F).

> Laboratorio de simulación con fines académicos, hecho con una base de datos de clase. No es una herramienta clínica validada ni sustituye el criterio médico.
